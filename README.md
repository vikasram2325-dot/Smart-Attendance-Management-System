# 📸 Smart Attendance Management System

## About the Project
Smart Attendance Management System is designed to record and manage student attendance digitally. It reduces paperwork and makes attendance tracking easier.

## Features
- Student Information Management
- Digital Attendance Recording
- Attendance Reports
- Daily Attendance Tracking
- Admin Login

## Technologies Used
- Python
- HTML, CSS, JavaScript
- MySQL

## Future Enhancements
- Face Recognition
- QR Code Attendance
- Automatic Monthly Reports

## Conclusion
The system provides a simple and efficient way to manage student attendance.
